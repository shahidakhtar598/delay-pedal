# Bina Android Studio ke APK Kaise Banayein (GitHub 1-Click Guide)

1. **GitHub par naya Private Repo banayein:**
   - [github.com](https://github.com) par login karein -> `+` -> **New repository** (naam rakhein `dd7x-vocal-delay`, Private select karein -> **Create repository**).
2. **Code upload karein:**
   - Is ZIP ko extract karein aur `dd7-vocal-delay-pedal` folder ke andar ki saari files/folders (`.github`, `android-app`, `license-backend`, `admin-tools`) ko GitHub repo mein upload ya `git push` kar dein.
   - *Tip:* Agar browser se upload kar rahe hain to hidden `.github` folder select karna na bhoolein (Windows/Mac mein Hidden Files ON kar lein), ya `git push` use karein.
3. **1-Click Build chalayein:**
   - Repo ke upar **Actions** tab par click karein -> left side mein **Build DD-7X Vocal Delay APK** select karein -> **Run workflow** button dabayein (apna WhatsApp number bhi wahin daal sakte hain).
4. **APK download karein:**
   - 3–4 minute mein green tick aa jayega. Us run par click karein -> neeche **Artifacts** section mein **DD7X-Vocal-Delay-APK** par click karke `.apk` download kar lein aur apne Android phone par install kar lein!
